# Illustration de démonstration

`salon_demo.png` : image fictive créée avec l’outil intégré ImageGen le 19 septembre 2026. Elle ne représente pas une annonce réelle et n’atteste aucun contrôle.

Prompt utilisé :

> Create one photorealistic illustrative real-estate listing image, landscape 3:2. A bright tasteful living room in a contemporary apartment in Dakar, Senegal, beige fabric sofa with muted olive cushions, wooden low coffee table, cream walls, wide windows with warm daylight, subtle green plants, realistic modest elegant rental apartment rather than a palace. Inspired by the neutral warm living room photographs commonly used in real estate app mockups. No text, no logos, no people, no UI, no watermark. This is an explicitly fictional demonstration property asset for Teranga Immo. Save image for use in app.

Le logo `assets/brand/logo_original.png` est une copie inchangée du fichier fourni par l’utilisateur. Les références d’interface viennent des trois maquettes du ZIP utilisateur. Poppins est distribuée selon la licence OFL fournie dans `assets/fonts/OFL.txt`.
